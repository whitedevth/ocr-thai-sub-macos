# OCR Thai Sub

แอป macOS ที่รับภาพเกมจาก capture card แล้ว OCR ซับภาษาอังกฤษ แปลเป็นไทยด้วย Claude API และแสดงซับไทยทับบนภาพสด ๆ

## Build และเปิดแอป

```bash
./scripts/make-app.sh
open build/OCRThaiSub.app
```

ครั้งแรกที่เปิด macOS จะขอสิทธิ์ใช้กล้อง (สำหรับ capture card) และไมโครโฟน (สำหรับเสียงเกม)

## ใช้งาน

1. ต่อ capture card แล้วกด รีเฟรชอุปกรณ์ จากนั้นเลือกการ์ดที่แถบด้านบน
2. ใส่ Anthropic API key ในแผงตั้งค่า แล้วกด บันทึก key ลง Keychain
3. กด เริ่ม แล้วลากแถบเลื่อน "กรอบซับ" ให้กรอบสีเหลืองครอบซับของเกม
4. เลือกโหมดในแผงตั้งค่า:
   - **เฉพาะซับ:** อ่านเฉพาะกรอบซับ แปลเป็นบรรทัดเดียว เหมาะกับฉากเล่าเรื่อง
   - **ทั้งจอ:** อ่านทั้งจอ แยกข้อความเป็นกล่อง (เมนู ภารกิจ คำอธิบายไอเทม บทพูด) แปลเฉพาะกล่องที่ข้อความเปลี่ยน แล้ววางคำแปลไว้ตรงตำแหน่งเดิม ข้อความที่เป็นตัวเลขล้วน เช่น HP หรือเวลา จะถูกข้าม
5. เลือกตัวแปล:
   - **Claude (คลาวด์):** แปลได้ดีที่สุด ต้องมี API key
   - **Ollama (ในเครื่อง):** ไม่ใช้เน็ต ไม่มีค่าใช้จ่าย ต้องติดตั้ง Ollama และโหลดโมเดลก่อน เช่น `ollama pull gemma3:12b`
6. ถ้าใส่ชื่อเกมและชื่อตัวละครในช่อง "ข้อมูลเกม" คำแปลจะเรียกชื่อได้คงที่กว่า

## โครงสร้าง

- `Sources/SubtitleCore`: OCR (Apple Vision), ตัวกันซับกระพริบ, ตัวแปล Claude, Keychain
- `Sources/OCRThaiSub`: แอป SwiftUI (รับภาพ, preview, overlay, ตั้งค่า)
- `swift test`: ทดสอบ tracker และ OCR บนภาพจำลอง 1080p
